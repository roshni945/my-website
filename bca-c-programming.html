💻 1. Introduction to C

C is a general-purpose, procedural programming language. It is widely used for system programming, embedded systems and application development.

⭐ Basic C Program

#include <stdio.h> int main() { printf("Hello, World!"); return 0; }

🔍 Important Parts

  • 📚 #include <stdio.h> → Includes the standard input/output header.
  • 🚀 main() → Starting point of the program.
  • 🖨️ printf() → Displays output.
  • ✅ return 0; → Indicates successful program termination.

📦 2. Variables & Data Types

A variable is a named memory location used to store data.

int age = 20; float marks = 85.5; char grade = 'A';

🔢 Common C Data Types

🔢 int
Integer values
🔢 float
Decimal values
🔢 double
More precise decimal values
🔤 char
Single character
💡 Example:

int age = 20; stores the integer value 20 in the variable named age.

➕ 3. Operators

Operators are symbols used to perform operations on values and variables.

➕ Arithmetic

+   -   *   /   %

🔍 Relational

>   <   ==   !=   >=   <=

🧠 Logical

&&   ||   !

📝 Assignment

=   +=   -=   *=

💻 Example
int a = 10; int b = 5; int sum = a + b; int product = a * b;

🔀 4. if-else

The if-else statement is used to make decisions based on a condition.

▶️ Start
→
🔍 Condition
→
✅ True
→
❌ False
💻 Example
#include <stdio.h> int main() { int age = 18; if(age >= 18) { printf("Eligible"); } else { printf("Not Eligible"); } return 0; }

🔘 5. switch Statement

The switch statement is used when one expression needs to be compared with multiple possible values.

switch(choice) { case 1: printf("Option 1"); break; case 2: printf("Option 2"); break; default: printf("Invalid choice"); }
💡 Important:

The break statement is commonly used to exit a case.

🔁 6. Loops

Loops are used to execute a block of statements repeatedly.

🔁 for Loop

Useful when the number of repetitions is known.

🔄 while Loop

Checks the condition before execution.

🔁 do-while Loop

Executes the body at least once.

💻 for Loop Example
for(int i = 1; i <= 5; i++) { printf("%d\n", i); }

⚙️ 7. Functions

A function is a block of code designed to perform a particular task.

📥 Input
→
⚙️ Function
→
📤 Return Value
💻 Function Example
#include <stdio.h> int add(int a, int b) { return a + b; } int main() { int result = add(10, 20); printf("%d", result); return 0; }

✨ Advantages

  • ♻️ Code reusability
  • 🧹 Reduces repetition
  • 📖 Improves readability
  • 🛠️ Easier maintenance

📊 8. Arrays

An array stores multiple values of the same data type in a contiguous collection.

[0] 10
[1] 20
[2] 30
[3] 40
💻 Array Example
int marks[5] = {80, 75, 90, 85, 88}; printf("%d", marks[0]);
💡 Remember:

C array indexing starts from 0.

🔤 9. Strings

In C, a string is a sequence of characters stored in a character array and terminated by the null character \0.

💻 String Example
char name[] = "Roshni"; printf("%s", name);

🧰 Common String Functions

🔢 strlen()
Finds string length
🔗 strcat()
Joins strings
📋 strcpy()
Copies a string
🔍 strcmp()
Compares strings

👉 10. Pointers

A pointer is a variable that stores the memory address of another variable.

📦 Variable
value = 10
→
📍 Address
→
👉 Pointer
💻 Pointer Example
int number = 10; int *ptr = &number; printf("%d", *ptr);
⭐ Important Symbols:

& → address-of operator
* → dereference operator

🏗️ 11. Structures

A structure is a user-defined data type that allows different types of data to be grouped together.

💻 Structure Example
