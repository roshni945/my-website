🧠 1. Algorithms

An algorithm is a finite sequence of clear, step-by-step instructions used to solve a problem or perform a task.

💡 Remember:

A good algorithm should be clear, finite and effective.

✨ Characteristics

  • 📌 Clearly defined steps
  • ⏳ Must eventually terminate
  • 🎯 Produces the required result
  • 🧩 Easy to understand

🔀 2. Flowcharts

A flowchart is a graphical representation of an algorithm using standard symbols.

🟢 Start
↓
📥 Input
↓
⚙️ Process
↓
📤 Output
↓
🔴 End

🔷 Common Symbols

  • 🟢 Oval → Start / End
  • ▭ Rectangle → Process
  • ◇ Diamond → Decision
  • ▱ Parallelogram → Input / Output
  • ➡️ Arrow → Flow direction

💡 3. Programming Logic

Programming logic means thinking about a problem step by step and creating instructions that a computer can execute.

🔍 Understand the problem
🧩 Break it into smaller parts
🧠 Design the logic
💻 Write the program

📦 4. Variables

A variable is a named location used to store a value that may change during program execution.

age = 20
name = "Roshni"
marks = 85
💡 Example:

Here, age, name and marks are variables.

🔢 5. Data Types

Data types define the type of value that a variable can store.

🔢 Integer
🔢 Floating Point
🔤 Character
📝 String
✅ Boolean

➕ 6. Operators

Operators are symbols used to perform operations on values and variables.

➕ Arithmetic

+   −   ×   ÷   %

🔍 Relational

>   <   ==   !=

🧠 Logical

AND   OR   NOT

📝 Assignment

=   +=   -=

🔀 7. Conditional Statements

Conditional statements allow a program to execute different instructions depending on whether a condition is true or false.

🔹 if
🔹 if-else
🔹 else-if
🔹 switch

🔁 8. Loops

Loops are used to execute a block of code repeatedly.

▶️ Start
→
🔍 Check Condition
→
⚙️ Execute
→
🔁 Repeat
🔁 for loop
🔄 while loop
🔁 do-while loop

⚙️ 9. Functions

A function is a reusable block of code designed to perform a specific task.

function greet() {
  console.log("Hello");
}

✨ Advantages

  • ♻️ Code reusability
  • 🧹 Reduces repetition
  • 📖 Improves readability
  • 🛠️ Easier maintenance

📊 10. Arrays

An array is a collection of elements stored under one variable name, usually accessed using an index.

[0] 10
[1] 20
[2] 30
[3] 40
💡 Important:

In many programming languages, array indexing starts from 0.

🔤 11. Strings

A string is a sequence of characters used to represent text.

name = "Roshni"
message = "Hello World"

✨ Common String Operations

  • 🔗 Concatenation
  • 🔍 Searching
  • ✂️ Slicing
  • 📏 Finding length
  • 🔄 Changing case
