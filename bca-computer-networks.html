🌐 1. Network Basics

A computer network is a collection of connected computers and devices that communicate with each other and share resources.

  • 💻 Computers can communicate with other devices.
  • 📁 Files and information can be shared.
  • 🖨️ Devices such as printers can be shared.
  • 🌍 Networks make Internet communication possible.

🏠 2. LAN / WAN

🏠 LAN

LAN stands for Local Area Network. It connects devices in a small geographical area, such as a home, school or office.

🌍 WAN

WAN stands for Wide Area Network. It connects networks across large geographical areas, such as cities or countries.

Feature LAN WAN
📍 Coverage Small area Large area
⚡ Speed Usually faster Usually slower than LAN
🏫 Example School network Internet

🧅 3. OSI Model

The OSI model divides network communication into seven layers.

7️⃣ Application Application Services
6️⃣ Presentation Data Format
5️⃣ Session Sessions
4️⃣ Transport Reliable Delivery
3️⃣ Network Routing
2️⃣ Data Link Frames
1️⃣ Physical Bits

🔗 4. TCP/IP

TCP/IP is a group of communication protocols used for communication between devices over networks.

🌐 Application
🚚 Transport
📍 Internet
🔌 Network Access

📍 5. IP Address

An IP address is a numerical address used to identify a device on a network.

Example IPv4 Address
192 168 1 10
  • 🔢 IPv4 uses 32 bits.
  • 🌐 IPv4 is commonly written in dotted-decimal form.
  • 📱 Devices use IP addresses for network communication.

📡 6. Network Devices

🔀 Switch

Connects devices within a network.

📡 Router

Connects different networks.

📶 Modem

Connects a network to an Internet service.

📢 Hub

Broadcasts data to connected devices.

🌍 7. Internet

The Internet is a global network of interconnected networks that allows computers and devices to communicate and exchange information.

  • 🌐 Websites can be accessed through the Internet.
  • 📧 Email uses Internet communication.
  • ☁️ Cloud services use Internet connectivity.
  • 💬 Online communication depends on Internet networks.
  • 🔎 Search engines help users find information online.

🔐 8. Basic Network Security

Network security helps protect networks, devices and information from unauthorized access and threats.

🔑

Strong Passwords

Use strong and unique passwords for accounts and devices.

🛡️

Firewall

A firewall helps control incoming and outgoing network traffic.

🔒

Encryption

Encryption helps protect information during communication.
