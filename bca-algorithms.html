🧠 1. Introduction to Algorithms

An algorithm is a finite sequence of well-defined steps used to solve a problem or perform a computation.

💡 Remember:

Algorithm = A clear step-by-step method for solving a particular problem.

⭐ 2. Characteristics of an Algorithm

📥 Input

Zero or more input values can be supplied.

📤 Output

The algorithm should produce a useful result.

🔍 Definiteness

Each step should be clear and unambiguous.

🏁 Finiteness

The process should eventually terminate.

🧩 3. Basic Algorithm Design

Algorithm design involves creating an effective sequence of operations to solve a problem.

  • 🔎 Understand the problem.
  • 📥 Identify inputs.
  • 📤 Identify outputs.
  • 🧩 Break the problem into smaller tasks.
  • ✍️ Write an algorithm or pseudocode.
  • 💻 Implement the solution.
  • 🧪 Test the solution.
  • ⚡ Improve efficiency if necessary.

📊 4. Algorithm Analysis

Algorithm analysis helps determine how efficiently an algorithm uses computational resources.

⏱️ Time Complexity

Describes how the number of operations grows as the input size increases.

💾 Space Complexity

Describes how additional memory usage grows with input size.

⏱️ 5. Time Complexity

Time complexity describes the growth of an algorithm's running time with respect to input size.

🟢 Constant

O(1)

Constant growth

🔵 Logarithmic

O(log n)

Slow growth

🟠 Linear

O(n)

Proportional growth

🔴 Quadratic

O(n²)

Faster growth

🔎 6. Searching Algorithms

Searching algorithms locate a target element within a collection of data.

🔍 Linear Search

Checks elements sequentially until the target is found or the collection ends.

⏱️ Worst case: O(n)

⚡ Binary Search

Repeatedly divides a sorted search range into two parts.

⏱️ Worst case: O(log n)

🔄 7. Sorting Algorithms

Sorting means arranging data elements into a particular order, such as ascending or descending.

🫧 Bubble Sort

Compares adjacent elements and swaps them when they are in the wrong order.

🃏 Insertion Sort

Inserts elements into their appropriate position in the sorted part.

🎯 Selection Sort

Selects the appropriate minimum or maximum element and places it into position.

⚡ Quick Sort

Uses partitioning around a pivot to divide the problem.

💻 Bubble Sort
for(int i = 0; i < n - 1; i++) { for(int j = 0; j < n - i - 1; j++) { if(arr[j] > arr[j + 1]) { int temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp; } } }

♻️ 8. Recursion

Recursion is a technique in which a function calls itself to solve a smaller version of a problem.

⚠️ Important:

A recursive solution needs a suitable base case to stop the recursive calls.

💻 Factorial Example
int factorial(int n) { if(n == 0) return 1; return n * factorial(n - 1); }

🧠 9. Basic Algorithmic Problem Solving

  • 🔎 Understand the problem.
  • 📥 Identify the input.
  • 📤 Identify the expected output.
  • 🧩 Divide the problem into smaller parts.
  • ✍️ Create pseudocode or an algorithm.
  • 💻 Write the program.
  • 🧪 Test with different inputs.
  • ⚡ Analyze and improve the solution.
🚀 Problem-Solving Formula:

Problem → Plan → Algorithm → Code → Test → Improve

📋 10. Important Algorithm Comparison

Algorithm Category Common Complexity Key Idea
Linear Search 🔎 Searching O(n) worst case Sequential checking
Binary Search 🔎 Searching O(log n) worst case Divide search range
Bubble Sort 🔄 Sorting O(n²) worst case Adjacent swapping
Insertion Sort 🔄 Sorting O(n²) worst case Insert into sorted part
Selection Sort 🔄 Sorting O(n²) worst case Select minimum/maximum
Quick Sort 🔄 Sorting O(n²) worst case Partition around pivot

  • 🔎 Linear Search → Sequential search.
  • ⚡ Binary Search → Search by repeatedly dividing a sorted range.
  • 🔄 Sorting → Arranging data.
  • ♻️ Recursion → Function calling itself.
  • 📈 Big-O → Asymptotic growth notation.
