📘 Python Variables Introduction

A Python Variable is a name used to store data inside memory. Variables allow Python programs to save numbers, text, lists, objects and many other values.

Python automatically decides the data type, so you don't need to declare it like C or Java.

💡 Quick Tip

Think of a variable as a labelled box. You give the box a name and store any value inside it.

⚠ Common Beginner Mistake

Don't use spaces in variable names. Example: 

student name = "Roshni" ❌

student_name = "Roshni" ✅

📝 Python Variable Syntax

Python me variable banana bahut easy hai. Bas variable ka naam likho aur "=" ke baad value assign kar do. 

x = 10
name = "Roshni"
price = 99.99
isStudent = True

💻 Python Variables Example

name = "Roshni"
age = 19
city = "Mumbai"

print(name)
print(age)
print(city)

✅ Output

Roshni
19
Mumbai

📜 Python Variable Rules

  • ✅ Variable name must start with a letter or underscore (_).
  • ✅ It can contain letters, numbers and underscores.
  • ❌ It cannot start with a number.
  • ❌ Spaces are not allowed.
  • ❌ Python keywords cannot be used as variable names.
  • ✅ Variable names are case-sensitive.

✍ Python Naming Rules

Valid ✅ Invalid ❌
student_name student name
age2 2age
total_marks total-marks
userName class

🔄 Assign Multiple Variables

You can assign values to multiple variables in one line.

x, y, z = 10, 20, 30

print(x)
print(y)
print(z)

✅ Output

10
20
30

🖨 Output Variables

Use print() to display variables.

name = "Roshni"

print(name)

age = 19

print(age)

💡 Tip

You can print multiple variables together. 

print(name, age)
