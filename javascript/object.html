💡 Quick Concept

A JavaScript Object stores data in key-value pairs.

Example:
name → "Roshni"

📌 What is a JavaScript Object?

A JavaScript Object is a collection of related information stored as key-value pairs. Objects help us organize data in a structured way. Instead of creating many separate variables, we can store everything inside one object.

🧩 Object Structure 


Property   :   Value

name       :   "Roshni"

age        :   20

course     :   "BCA"

📝 Object Syntax

Objects are created using curly braces { }. Each property has a name (key) and a value. 

let student = {

    name: "Roshni",

    age: 20,

    course: "BCA"

};

💻 Example Program 

let student = {

    name: "Roshni",

    age: 20,

    course: "BCA"

};

console.log(student);

👀 Output 

{
  name: "Roshni",
  age: 20,
  course: "BCA"
}

🔍 Accessing Object Properties

We can access object properties using Dot Notation or Bracket Notation. 

let student = {

    name: "Roshni",

    age: 20,

    course: "BCA"

};

console.log(student.name);

console.log(student["course"]);

Roshni

BCA

➕ Adding a New Property

New properties can be added at any time. 

student.city = "Mumbai";

console.log(student);

{
  name: "Roshni",
  age: 20,
  course: "BCA",
  city: "Mumbai"
}

🗑️ Deleting a Property

Use the delete keyword to remove a property from an object. 

delete student.age;

console.log(student);

⚙️ Object Methods

An object can also contain functions. These functions are called Object Methods. 

let person = {

    name: "Roshni",

    greet: function(){

        return "Hello " + this.name;

    }

};

console.log(person.greet());

Hello Roshni
