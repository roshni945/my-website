📌 What are JavaScript Variables?

Variables are containers used to store data in JavaScript. They allow us to save information such as text, numbers, boolean values, arrays, objects and much more.

Instead of writing the same value again and again, we store it in a variable and reuse it whenever needed.

💡 Variable Example 


name  →  "Roshni"

age   →  20

city  →  "Mumbai"

🟣 var Keyword

The var keyword was used in older versions of JavaScript. Today, it is mostly replaced by let and const because they provide better control over variables. 

var student = "Roshni";

console.log(student);

Roshni

🔵 let Keyword

The let keyword is used for variables whose values may change later in the program. 

let age = 18;

age = 19;

console.log(age);

19

🟢 const Keyword

Use const when the value should remain constant. Once assigned, it cannot be reassigned. 

const country = "India";

console.log(country);

India

⚡ var vs let vs const

🟣 var

🔵 let

🟢 const

Value cannot be reassigned

📌 Variable Naming Rules

Follow these rules while naming variables in JavaScript.

  • ✅ Start with a letter, underscore (_) or dollar sign ($).
  • ✅ Variable names are case-sensitive.
  • ✅ Use meaningful names.
  • ❌ Do not start with numbers.
  • ❌ Do not use JavaScript reserved keywords.

✔ Valid and ❌ Invalid Variable Names

✅ userName
✅ totalMarks
✅ _student
❌ 123name
❌ let
❌ user-name

🌍 Global vs Local Variables

A Global Variable can be accessed from anywhere in the program.

A Local Variable is only available inside the block or function where it is created. 

let language = "JavaScript";

function showLanguage(){

    let level = "Beginner";

    console.log(language);

    console.log(level);

}

showLanguage();

JavaScript

Beginner

💻 Real-Life Example

⭐ Best Practices

  • ✅ Use const by default.
  • ✅ Use let if the value changes.
  • ❌ Avoid using var in modern JavaScript.
  • ✅ Choose meaningful variable names.
  • ✅ Keep variable names short and readable.

⚠ Common Mistakes

  • Using var everywhere.
  • Trying to reassign a const variable.
  • Using unclear variable names like x, y or z.
  • Creating unnecessary global variables.
