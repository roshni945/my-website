JavaScript Output Methods

JavaScript provides different ways to display output on a webpage or in the browser console.

1. console.log()

The console.log() method is used to display messages in the browser console. 

console.log("Hello JavaScript");

Output:

Hello JavaScript

2. document.write()

The document.write() method writes content directly into an HTML page. 

document.write("Welcome to Roshni Code Charm");

3. alert()

The alert() method shows a popup message to the user. 

alert("Welcome!");

4. innerHTML

The innerHTML property is used to change HTML content using JavaScript. 

document.getElementById("demo").innerHTML =
"Hello JavaScript";
