📌 What are JavaScript Operators?

JavaScript Operators are special symbols used to perform different types of operations on variables and values.

They help us perform mathematical calculations, compare values, assign data and write logical conditions in programs.

🧩 Simple Example 


let a = 10;

let b = 5;

let sum = a + b;

console.log(sum);

➕ Arithmetic Operators

Arithmetic Operators are used to perform mathematical calculations such as addition, subtraction, multiplication and division. 

let a = 20;

let b = 5;

console.log(a + b);

console.log(a - b);

console.log(a * b);

console.log(a / b);

console.log(a % b);

console.log(a ** 2);

⚖️ Comparison Operators

Comparison Operators compare two values and always return either true or false.

🏷 typeof Operator

The typeof operator returns the data type of a value or variable.

console.log(typeof name);

console.log(typeof age);

⭐ Operator Precedence

Operator Precedence decides which operation JavaScript performs first when multiple operators are used in one expression. 

let result = 10 + 5 * 2;

console.log(result);

20

💡 Explanation

Multiplication (*) has a higher precedence than Addition (+). Therefore, 5 × 2 = 10 then 10 + 10 = 20.

💡 Pro Tip

Use parentheses () whenever an expression becomes difficult to read. This makes your code easier to understand and avoids unexpected results.

⚠ Common Mistakes

  • Using = instead of == or ===.
  • Confusing == with ===.
  • Ignoring operator precedence.
  • Using logical operators without understanding the conditions.
