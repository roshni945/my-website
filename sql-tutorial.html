🗄️ 1. DBMS Basics

DBMS stands for Database Management System. It is software used to create, store, organize and manage data in databases.

💡 Simple Meaning:

A DBMS helps users store and manage large amounts of data efficiently.

👤
User

Gives request

💻
DBMS

Processes request

🗄️
Database

Stores data

⭐ Functions of DBMS

  • 🗃️ Data storage
  • 🔍 Data retrieval
  • 🔐 Data security
  • 👥 Multi-user access
  • 💾 Backup and recovery
  • 🔄 Data management

🗃️ 2. Database & Relational Database

A database is an organized collection of related information that can be easily accessed and managed.

🔗 Relational Database

A relational database stores data in tables made up of rows and columns.

🔑 4. Database Keys

Keys are used to identify records and establish relationships between tables.

🔐 Primary Key

Uniquely identifies each record in a table.

🔗 Foreign Key

Creates a relationship between two tables.

🔑 Candidate Key

A field that can potentially become a primary key.

🧩 Composite Key

A key made using two or more columns.

💻 5. SQL

SQL stands for Structured Query Language. It is used to communicate with relational databases.

📚 Major SQL Command Categories

🏗️ DDL

CREATE, ALTER, DROP, TRUNCATE

📝 DML

INSERT, UPDATE, DELETE

🔍 DQL

SELECT

🔐 DCL

GRANT, REVOKE

🔄 TCL

COMMIT, ROLLBACK, SAVEPOINT

🔍 6. SELECT Command

SELECT is used to retrieve data from a table.

💻 Select All Columns
SELECT * FROM students;
💻 Select Specific Columns
SELECT name, marks FROM students;
🔎 WHERE Example
SELECT * FROM students WHERE marks > 80;

➕ 7. INSERT Command

INSERT is used to add new records into a table.

💻 INSERT Example
INSERT INTO students (name, course, marks) VALUES ('Riya', 'BCA', 85);
📌 Remember:

INSERT adds a new record.

✏️ 8. UPDATE Command

UPDATE is used to modify existing records.

💻 UPDATE Example
UPDATE students SET marks = 90 WHERE student_id = 101;
⚠️ Important:

Always use a suitable WHERE condition when updating specific records.

🗑️ 9. DELETE Command

DELETE is used to remove records from a table.

💻 DELETE Example
DELETE FROM students WHERE student_id = 101;
⚠️ Important:

A DELETE statement without a WHERE condition can remove all records.

🔗 10. SQL JOINs

JOINs are used to combine related data from two or more tables.

👨‍🎓
Students

Student_ID

🔗
JOIN

Common column

📚
Courses

Course_ID

🔵 INNER JOIN

Returns matching records from both tables.

🟢 LEFT JOIN

Returns all records from the left table and matching records from the right.

🟣 RIGHT JOIN

Returns all records from the right table and matching records from the left.

🟠 FULL OUTER JOIN

Returns matching and non-matching records.

💻 INNER JOIN Example
SELECT students.name, courses.course_name FROM students INNER JOIN courses ON students.course_id = courses.course_id;

📊 11. Aggregate Functions

Aggregate functions perform calculations on a group of records.

🔢 COUNT()

Counts records.

➕ SUM()

Calculates total.

📈 AVG()

Calculates average.

⬆️ MAX()

Finds maximum value.

⬇️ MIN()

Finds minimum value.

💻 Example
SELECT AVG(marks) FROM students;

🔐 13. Database Transactions

A transaction is a sequence of database operations treated as a single logical unit.

🔐 ACID Properties

🅰️ Atomicity

A transaction is completed fully or not at all.

🅲️ Consistency

Database remains in a valid state.

🅸️ Isolation

Transactions work independently from each other.

🅳️ Durability

Committed changes remain saved.

💻 Transaction Example
START TRANSACTION; UPDATE accounts SET balance = balance - 500 WHERE id = 1; COMMIT;
