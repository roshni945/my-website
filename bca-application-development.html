Mobile App Basics

A mobile application is software designed to run on smartphones and tablets.

🤖 Android Apps

Applications designed mainly for Android smartphones and tablets.

🍎 iOS Apps

Applications developed for Apple devices such as iPhone and iPad.

🎨 User Interface

The screens, buttons, menus and controls through which users interact.

⚙️ App Logic

The programming that controls how an application behaves.

🌐

Web Applications

Web applications are software programs accessed through a web browser.

🖥️ Frontend

The visible part of a web application that users interact with.

⚙️ Backend

Handles application logic, processing and data operations.

🗄️ Database

Stores and manages application data.

🌍 Browser

Software such as Chrome, Edge or Firefox used to access web applications.

🔗
