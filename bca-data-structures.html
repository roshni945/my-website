🧠 1. Introduction to Data Structures

A data structure is a way of organizing and storing data so that it can be accessed and processed efficiently.

💡 Simple Meaning:

Data Structure = A method of organizing data.

📌 Types of Data Structures

📦 Linear

Array, Linked List, Stack and Queue.

🌳 Non-Linear

Trees and Graphs.

📦 2. Arrays

An array is a collection of elements stored in contiguous memory locations.

[10]
[20]
[30]
[40]

⭐ Advantages

  • ⚡ Fast access using index.
  • 📦 Simple structure.
  • 💾 Efficient for fixed-size data.

⚠️ Limitation

The size of a traditional array is generally fixed, so inserting or deleting elements can require shifting other elements.

💻 Example
int numbers[5] = {10, 20, 30, 40, 50};

📚 4. Stack

Stack follows the LIFO principle: Last In, First Out.

🟦 30
🟦 20
🟦 10
🍽️ Real-Life Example:

A stack of plates — the last plate placed on top is removed first.

⚙️ Main Operations

  • ➕ Push → Add an element.
  • ➖ Pop → Remove the top element.
  • 👀 Peek → View the top element.

🚶 5. Queue

Queue follows the FIFO principle: First In, First Out.

→
👤 B

🛒 Real-Life Example:

People standing in a queue at a counter. The person who comes first is served first.

⚙️ Main Operations

  • ➕ Enqueue → Add an element.
  • ➖ Dequeue → Remove an element.
  • 👀 Front → First element.

🔎 8. Searching

Searching means finding a particular element in a collection of data.

🔍 Linear Search

Checks elements one by one.

⏱️ Time Complexity: O(n)

⚡ Binary Search

Repeatedly divides a sorted search space into two parts.

⏱️ Time Complexity: O(log n)

💻 Linear Search
for(int i = 0; i < n; i++) { if(arr[i]==key) { printf("Element Found"); } }

🔄 9. Sorting

Sorting means arranging data in a particular order, such as ascending or descending order.

🔀 40
→
🔄 Sort
→
📊 10 20 30 40

🫧 Bubble Sort

Repeatedly compares adjacent elements and swaps them when needed.

🃏 Insertion Sort

Builds the sorted portion one element at a time.

🔀 Selection Sort

Selects the smallest element and places it in the correct position.

⚡ Quick Sort

Uses a pivot to divide the data into smaller parts.
