💻 1. Computer Basics

A computer is an electronic programmable device that accepts data, processes it according to instructions, stores it and produces useful information.

💡 Simple Definition

A computer takes input, processes the data, stores information and produces output.

🔄 Basic Working of Computer

⌨️ Input
→
⚙️ Processing
→
💾 Storage
→
🖥️ Output

✨ Characteristics of Computer

  • ⚡ High speed
  • 🎯 Accuracy
  • 💾 Large storage capacity
  • 🔄 Automation
  • 📋 Consistency
  • 🧩 Versatility

🧩 2. Hardware & Software

🔧 Hardware

Hardware refers to the physical components of a computer that can be seen and touched.

  • 🖥️ Monitor
  • ⌨️ Keyboard
  • 🖱️ Mouse
  • 🧠 CPU
  • 🖨️ Printer

💿 Software

Software is a collection of programs and instructions that tells the computer what to do.

  • 🪟 Windows
  • 🌐 Web Browser
  • 📝 Word Processor
  • 📊 Spreadsheet

📊 Hardware vs Software

🔧 Hardware 💿 Software
Physical components Programs and instructions
Can be touched Cannot be physically touched
Keyboard Web Browser

⌨️ 3. Input & Output Devices

⌨️ Input Devices

Devices used to enter data and instructions into a computer.

  • ⌨️ Keyboard
  • 🖱️ Mouse
  • 📄 Scanner
  • 🎙️ Microphone
  • 📷 Webcam
  • 📱 Touchscreen

🖥️ Output Devices

Devices that present the processed information to the user.

  • 🖥️ Monitor
  • 🖨️ Printer
  • 🔊 Speaker
  • 📽️ Projector
  • 🎧 Headphones

⚙️ 4. Operating Systems

An Operating System (OS) is system software that manages computer hardware and provides services for application programs.

🛠️ Functions of Operating System

  • 🧠 Memory management
  • 📁 File management
  • ⚙️ Process management
  • 🔐 Security management
  • 🖥️ User interface
  • 🔌 Device management

💻 Examples

🪟 Windows
🐧 Linux
🍎 macOS
📱 Android

🔢 5. Number Systems

A number system is a method of representing numbers using a specific set of digits and a base.

🔟 Decimal

Base 10

Digits: 0–9

💻 Binary

Base 2

Digits: 0 and 1

🧮 Octal

Base 8

Digits: 0–7

🔤 Hexadecimal

Base 16

Digits: 0–9 and A–F

🧠 6. Computer Memory

Computer memory is used to store data, instructions and information required by the computer.

⚡ Primary Memory

  • RAM: Temporary working memory.
  • ROM: Non-volatile memory used to store important instructions.
  • Cache: Very fast memory located close to or associated with the processor.

💾 Secondary Storage

  • 💽 Hard Disk
  • ⚡ SSD
  • 🔌 USB Drive
  • 💳 Memory Card
  • 💿 Optical Disc

🌐 7. Internet Basics

The Internet is a global network of interconnected computers and devices that communicate and exchange information.

🌐 Website

A collection of related web pages available on the Web.

🔗 URL

The address used to locate a resource on the Web.

🌎 Browser

Software used to access and view websites.

🔍 Search Engine

A service that helps users find information online.

🔗 8. Networking Basics

A computer network is a group of connected devices that can communicate and share data and resources.

🌍 Types of Networks

📱 PAN

Personal Area Network

🏠 LAN

Local Area Network

🏙️ MAN

Metropolitan Area Network

🌍 WAN

Wide Area Network

🔌 Networking Devices

  • 📡 Router
  • 🔀 Switch
  • 🌐 Modem
  • 🔁 Hub
  • 📶 Access Point

📝 Quick Revision

  • 💻 Computer accepts input, processes data and produces output.
  • 🔧 Hardware consists of physical components.
  • 💿 Software consists of programs and instructions.
  • ⌨️ Input devices enter data.
  • 🖥️ Output devices display results.
  • ⚙️ Operating System manages computer resources.
  • 🔢 Binary number system uses 0 and 1.
  • 🧠 RAM is temporary working memory.
  • 🌐 Internet connects computers and devices globally.
  • 🔗 Networking allows devices to communicate and share resources.
