🐍 1. Python Basics

Python is a high-level, interpreted and general-purpose programming language. It is known for its simple and readable syntax.

⭐ First Python Program

print("Hello, World!")

💡 Why learn Python?

Python is beginner-friendly and is used in web development, automation, data analysis, AI, machine learning and many other areas.

📦 2. Variables

A variable is a name used to store a value. Python automatically determines the type of the value.

name = "Roshni" age = 20 marks = 85.5
👤 name
Stores text
🔢 age
Stores integer
📊 marks
Stores decimal value
💡 Python
No separate declaration needed

🔢 3. Data Types

Data types define the kind of value stored in a variable.

🔢 int
Whole numbers
💧 float
Decimal numbers
🔤 str
Text
✅ bool
True / False
📋 list
Ordered collection
🔗 tuple
Ordered immutable collection
📖 dict
Key-value collection
🎯 set
Unique unordered values
💻 Check Data Type
age = 20 print(type(age))

➕ 4. Operators

Operators are symbols used to perform operations on values.

➕ Arithmetic

+   -   *   /   %   **   //

🔍 Comparison

==   !=   >   <   >=   <=

🧠 Logical

and   or   not

📝 Assignment

=   +=   -=   *=

a = 10 b = 5 print(a + b) print(a * b)

🔀 5. Conditions

Conditional statements allow a program to make decisions.

▶️ Start
→
🔍 Condition
→
✅ True / ❌ False
💻 if-else Example
age = 18 if age >= 18: print("Eligible") else: print("Not Eligible")

🧩 elif

marks = 75 if marks >= 90: print("A") elif marks >= 60: print("B") else: print("C")

🔁 6. Loops

Loops are used to execute code repeatedly.

🔁 for Loop

Used to iterate over a sequence.

🔄 while Loop

Repeats while a condition is true.

💻 for Loop
for i in range(1, 6): print(i)
💻 while Loop
i = 1 while i <= 5: print(i) i +=1

📥 Input
→
⚙️ Function

def add(a, b): return a + b result = add(10, 20) print(result)

✨ Advantages

  • 📖 Improves readability

📋 8. Lists

A list is an ordered and mutable collection of elements.

[0] Apple
[1] Mango
[2] Banana
💻 List Example
fruits = ["Apple", "Mango", "Banana"] print(fruits[0]) fruits.append("Orange") print(fruits)

🧰 Common List Methods

➕ append()
❌ remove()
🔢 sort()
🧹 clear()

🔗 9. Tuples

A tuple is an ordered collection that cannot normally be changed after creation.

numbers = (10, 20, 30, 40) print(numbers[0])
💡 Remember:

Lists are generally mutable, while tuples are generally immutable.

📖 10. Dictionaries

A dictionary stores data in key : value pairs.

🔑 name
→
👤 Roshni
🔑 age
→
🔢 20
💻 Dictionary Example
student = { "name": "Roshni", "age": 20, "course": "BCA" } print(student["name"])

🎯 11. Sets

A set is an unordered collection of unique elements.

numbers = {10, 20, 30, 20} print(numbers)
⭐ Key Point:

Sets automatically remove duplicate values.

🧰 Common Set Methods

➕ add()
❌ remove()
🔗 union()
🔍 intersection()

📁 12. File Handling

File handling allows Python programs to read and write data stored in files.

💻 Python Program
→
📂 File
→
💾 Data
✍️ Write to a File
file = open("data.txt", "w") file.write("Hello Python") file.close()
📖 Read from a File
file = open("data.txt", "r") data = file.read() print(data) file.close()
💡 Common Modes:

r → Read
w → Write
a → Append
