MS Excel

Spreadsheet software for data and calculations

Microsoft Excel is a spreadsheet application used to enter, organize, calculate, analyze and visualize data.

📋 Workbook

An Excel file is called a workbook. A workbook can contain multiple worksheets.

📄 Worksheet

A worksheet contains rows, columns and cells where data can be entered.

🔢 Cell

A cell is the intersection of a row and a column. Each cell has an address such as A1.

🧮 Formula

Formulas allow Excel to perform calculations automatically.

🧮 Example Excel Formula

=SUM(A1:A10)
💡 Important:

Excel is useful for calculations, data organization, reports, charts and many everyday office tasks.

Basic Statistics

Understanding and summarizing data

Statistics provides methods for collecting, organizing, summarizing and interpreting data.

➗

Mean

Average of a group of values.

🎯

Median

Middle value after arranging data.

🔁

Mode

Most frequently occurring value.

📐 Mean Formula

Mean = Sum of values ÷ Number of values
💡 Example:

For the values 10, 20 and 30, the mean is 20.

Data Visualization

Representing data visually

Data visualization represents information using charts, graphs and other visual formats so that patterns and comparisons can be understood more easily.

📊 Example — Monthly Data

📊 Bar Chart

Useful for comparing values between categories.

🥧 Pie Chart

Useful for showing parts of a whole.

📈 Line Chart

Useful for showing changes or trends over time.

📉 Scatter Plot

Useful for exploring relationships between numerical variables.

Chart Best Used For Example
Bar Chart Comparing categories Sales by product
Pie Chart Parts of a whole Budget distribution
Line Chart Trends over time Monthly sales
Scatter Plot Relationships Study time vs marks

Communicating information clearly

Presentation skills help you communicate ideas, information and results clearly to an audience.

🗣️ Explain
❓ Answer
  • Keep slides simple and easy to read.
  • Use headings to organize information.
