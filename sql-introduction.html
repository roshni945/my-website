📘 What is SQL?

SQL (Structured Query Language) is a programming language used to store, manage, and manipulate data inside databases.

Using SQL, we can create databases, insert data, update records, delete information and retrieve data using powerful queries.

💡 Real World Example

When you use Instagram, Amazon or banking apps, millions of records are stored inside databases. SQL helps these applications manage that data.

✨ Quick Tip: SQL is one of the most important skills for Web Developers, Data Analysts and Software Engineers.

🗄 Database Concepts

A database is an organized collection of information that can be easily accessed and managed.

  • Database stores data
  • Tables organize information
  • Rows represent records
  • Columns represent attributes

📝 SQL Syntax

SQL commands follow a simple structure. Most SQL statements start with a keyword and work with database tables.

Basic SQL Syntax 


SELECT column_name
FROM table_name;
💡 Remember: SQL keywords are not case-sensitive, but writing them in uppercase improves readability.

🔍 SELECT Statement

The SELECT statement is used to retrieve data from a database table.

Example: 


SELECT *
FROM students;

This query displays all records from the students table.

➕ INSERT Statement

INSERT command is used to add new records into a database table.

Example: 


INSERT INTO students
(name, age, course)
VALUES
('Riya', 20, 'BCA');

✏️ UPDATE Statement

UPDATE is used to modify existing data inside a table.

Example: 


UPDATE students
SET age = 21
WHERE name = 'Riya';

❌ DELETE Statement

DELETE removes records from a table.

Example: 


DELETE FROM students
WHERE name='Riya';
⚠️ Warning: Always use WHERE condition with DELETE, otherwise all records may be removed.

🔗 SQL Joins

SQL Joins are used to combine data from two or more tables based on a related column.

1. INNER JOIN

Returns only matching records from both tables. 


SELECT students.name, courses.course_name
FROM students
INNER JOIN courses
ON students.course_id = courses.id;

2. LEFT JOIN

Returns all records from the left table and matching records from the right table. 


SELECT *
FROM students
LEFT JOIN courses
ON students.course_id = courses.id;

3. RIGHT JOIN

Returns all records from the right table and matching records from the left table. 


SELECT *
FROM students
RIGHT JOIN courses
ON students.course_id = courses.id;
💡 SQL Tip: Learn SELECT, WHERE and JOIN properly. These are the most commonly used SQL concepts in real projects.
