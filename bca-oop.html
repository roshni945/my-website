🔒 3. Encapsulation

Encapsulation means combining data and methods into a single unit and controlling access to the data.

📦 Data
+
⚙️ Methods
→
🔒 Encapsulated Class
💻 Example
class BankAccount: def __init__(self): self.__balance = 0 def deposit(self, amount): self.__balance += amount def get_balance(self): return self.__balance account = BankAccount() account.deposit(1000) print(account.get_balance())
⭐ Key Point:

Encapsulation helps protect data and control how it is accessed.

🧬 4. Inheritance

Inheritance allows a new class to acquire properties and methods from an existing class.

👨 Parent Class
↓
👩 Child Class
💻 Python Example
class Animal: def eat(self): print("Eating") class Dog(Animal): def bark(self): print("Barking") dog = Dog() dog.eat() dog.bark()

🧬 Types of Inheritance

1️⃣ Single Inheritance
2️⃣ Multiple Inheritance
3️⃣ Multilevel Inheritance
4️⃣ Hierarchical Inheritance

🔄 5. Polymorphism

Polymorphism means "many forms". The same method or operation can behave differently in different situations.

⚙️ Same Method
→
🔄 Different Behaviour
💻 Example
class Dog: def sound(self): print("Bark") class Cat: def sound(self): print("Meow") animals = [Dog(), Cat()] for animal in animals: animal.sound()
💡 Remember:

One interface or method name can represent different behaviours.

🎯 6. Abstraction

Abstraction means hiding unnecessary implementation details and showing only the important features.

⚙️ Complex Implementation
→
🎯 Hide Details
→
👤 Simple Interface
🌍 Real-Life Example:

When using an ATM, you interact with buttons and options without needing to know the internal banking system.

💻 Basic Python Example
from abc import ABC, abstractmethod class Animal(ABC): @abstractmethod def sound(self): pass class Dog(Animal): def sound(self): print("Bark")

🏗️ 7. Constructors

A constructor is a special method that is automatically called when an object is created.

🏗️ Class
→
📦 Object Created
→
⚙️ __init__()
💻 Constructor Example
class Student: def __init__(self, name, age): self.name = name self.age = age student1 = Student("Roshni", 20) print(student1.name) print(student1.age)
⭐ Important:

In Python, __init__() is commonly used to initialize object attributes.

⚠️ 8. Exception Handling

Exception handling is used to handle runtime errors without abruptly stopping the program.

▶️ try
→
⚠️ Error?
→
🛠️ except
→
🧹 finally
💻 Example
try: number = int(input("Enter number: ")) print(10 / number) except ZeroDivisionError: print("Cannot divide by zero") except ValueError: print("Enter a valid number") finally: print("Program completed")
