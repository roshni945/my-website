🧱 2. HTML

HTML stands for HyperText Markup Language. It is used to create the structure of webpages.

📌 Common HTML Elements

🏷️ Headings — h1 to h6
📝 Paragraph — p
🔗 Links — a
🖼️ Images — img
📋 Lists — ul, ol, li
📦 Div — div
💻 Basic HTML
<!DOCTYPE html> <html> <head> <title>My Website</title> </head> <body> <h1>Hello World</h1> <p> Welcome to my website. </p> </body> </html>
⭐ Remember:

HTML provides the basic structure of a webpage.

Forms are used to collect information from users.

📋 Common Form Elements

📧 Email

☑️ Checkbox
🚀 Submit Button
💻 Form Example

📱 6. Responsive Web Design

Responsive Web Design means creating websites that work properly on different screen sizes such as computers, tablets and mobile phones.

🖥️ Desktop
📱 Tablet
📱 Mobile
💡 Goal:

The webpage should automatically adapt its layout to the user's screen.

💻 Media Query
@media (max-width: 600px) { body { font-size: 14px; } .container { padding: 15px; } }

🌳 7. DOM

DOM stands for Document Object Model. It represents an HTML document as a tree of objects.

💻 DOM Example

🖱️ 8. JavaScript Events

Events are actions or occurrences that happen in a webpage and can be handled using JavaScript.

🖱️ click
⌨️ keydown
🖱️ mouseover
📝 input
📋 submit
🌐 load
💻 Event Example
const button = document.getElementById("myButton"); button.addEventListener( "click", function() { alert("Button clicked!"); } );
