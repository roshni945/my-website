💡 SQL Quick Tip

SQL is used to communicate with databases. Start by understanding tables, rows and columns before moving to advanced queries.

⚠️ Common SQL Mistakes

  • Forgetting the semicolon at the end of a query.
  • Using incorrect column names.
  • Forgetting quotes around text values.
  • Using UPDATE or DELETE without a WHERE condition.
  • Not checking the table structure before writing queries.

💻 FIRST QUERY

Your First SQL Example

Start with a simple table and SELECT query.

🌱 Example SQL Code 
CREATE TABLE Students (
    id INT,
    name VARCHAR(50),
    course VARCHAR(50)
);

INSERT INTO Students
VALUES
(1, 'Riya', 'BCA'),
(2, 'Aarav', 'BCA');

SELECT * FROM Students;
