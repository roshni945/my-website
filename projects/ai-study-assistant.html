01 • INTRODUCTION

What is an AI Study Assistant?

An AI Study Assistant is a digital learning helper that uses artificial intelligence to support students while studying.

🤖

Your Digital Learning Helper

You can ask an AI study assistant to explain a difficult concept, create practice questions, summarize information, generate examples or help organize your study ideas.

The important part is to use AI as a learning assistant rather than simply copying its answers.

🧠

Learn Smarter

Ask questions and explore concepts in a way that is easier for you to understand.

🎯

Practice More

Create quizzes, examples and practice questions for revision.

04 • PROMPT LAB

Learn to Write Better Prompts

A clear prompt can make your AI interaction more useful and focused.

❌ BAD PROMPT

Tell me about Python.

This prompt is very broad and does not explain what the student actually wants.

✅ BETTER PROMPT

Explain Python variables to a beginner with three simple examples.

This prompt clearly mentions the topic, level and type of explanation required.

💻 Explain JavaScript functions to a beginner with two simple examples.
🐍 Create five Python practice questions about lists for beginners.
🗄️ Explain SQL JOINs using two simple tables.

07 • BE CAREFUL

Common Mistakes Students Should Avoid

❌

Copying Everything

Don't copy an AI answer without understanding it.

⚠️

Trusting Every Answer

AI can make mistakes, so verify important information.

🔐

Sharing Private Data

Avoid sharing passwords or other sensitive information.

🧠

Not Practicing

Use AI to learn, then practice the skill yourself.
