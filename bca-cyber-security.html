🛡️ 1. Security Basics

Cyber security is the practice of protecting computers, networks, applications and data from unauthorized access, damage and other digital threats.

  • 🔒 Protect personal and organizational information.
  • 💻 Keep devices and software updated.
  • 🛡️ Use security tools and safe practices.
  • 🔑 Protect accounts with strong authentication.

⚠️ 2. Threats & Vulnerabilities

A cyber threat is a potential danger to a computer system or network. A vulnerability is a weakness that may be exploited by a threat.

🎣

Phishing

Fraudulent messages or websites designed to trick users into revealing information.

🦠

Malware

Malicious software designed to harm, disrupt or gain unauthorized access to systems.

🔓

Weak Security

Weak passwords, outdated software or incorrect settings can create security vulnerabilities.

👤

Unauthorized Access

Accessing systems or information without proper permission.

🦠 3. Malware Awareness

Malware means malicious software. Different types of malware can affect computers and devices in different ways.

Malware Basic Meaning
🦠 Virus Malicious code that can attach to files and spread.
🐛 Worm Malware that can spread across networks automatically.
🔒 Ransomware Malware that can prevent access to data and demand payment.
👁️ Spyware Software designed to secretly collect information.

🔑 4. Authentication

Authentication is the process of verifying the identity of a user before allowing access to an account or system.

🔑

Something You Know

Example: Password or PIN.

📱

Something You Have

Example: Security key or registered device.

👆

Something You Are

Example: Biometric authentication.

🛡️

Multi-Factor Authentication

Uses more than one authentication factor for additional account protection.

🔐 5. Password Security

Strong password practices help reduce the risk of unauthorized access to accounts.

🔑 Strong Password

Use a long, unique password and avoid easily guessed personal information.

  • 🔑 Use unique passwords for important accounts.
  • 🚫 Avoid easily guessed information.
  • 🔒 Do not share passwords with others.
  • 🛡️ Enable multi-factor authentication when available.

🌐 7. Safe Internet Practices

Following safe online practices can help protect personal information and accounts.

🔗

Check Links

Be careful before opening unknown links or attachments.

🔒

Use Secure Websites

Check that websites use HTTPS when entering sensitive information.

📱

Update Devices

Keep operating systems and applications updated.

🛡️

Protect Accounts

Use strong passwords and additional authentication.

🎣

Avoid Phishing

Be cautious of suspicious emails, messages and websites.

💾

Backup Important Data

Keep appropriate backups of important information.
